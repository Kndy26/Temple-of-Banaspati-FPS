# 💀 Banaspati Curse - FPS Game

**Banaspati Curse** adalah game *First-Person Shooter* (FPS) bernuansa misteri fantasi lokal. Pemain harus menavigasi labirin gelap, mengumpulkan relik mistis, dan bertahan hidup dari serangan Banaspati. Game ini mengharuskan pemain menggunakan kecerdasan untuk membalikkan serangan bos demi menghancurkan segel pelindungnya.

> **Catatan Akademik:** Repositori ini hanya berisi *build* dikarenakan ukuran file project yang cukup besar. Project ini dibuat sebagai **Proyek Ujian Tengah Semester (UTS)** mata kuliah **Pemrograman Game** di **Universitas Bunda Mulia**.

---

## 🎮 Fitur Utama (Core Features)

* **FPS Mechanics:** Sistem menembak, *reload*, dan pergerakan senjata yang solid dan responsif.
* **Dynamic Maze & Objective System:** Sistem labirin dengan pengumpulan item (Boneka Santet & Tongkat Sakti) yang terintegrasi dengan UI objektif pemain. Pintu gerbang utama akan terbuka setelah semua item terkumpul.
* **Advanced Boss AI:** Bos tidak hanya menembak secara acak, melainkan menggunakan sistem *Predictive Aiming* yang menghitung kecepatan dan arah lari pemain untuk memprediksi tembakan ke masa depan.
* **Environmental Puzzles:** Pemain tidak bisa langsung melukai bos. Pemain harus memancing bos untuk menembakkan proyektil (Fireball), lalu berlindung di balik Patung Segel agar proyektil bos menghancurkan segelnya sendiri.
* **3D Spatial Audio & Lighting:** Sistem pencahayaan dinamis pada item *(Point Lights)* dan audio 3D yang suaranya memudar sesuai jarak tempuh pemain dari sumber suara.

## 🚀 Cara Bermain (How to Play)

Jika kamu hanya ingin memainkan game ini tanpa membuka *source code* di Unity, silakan ikuti langkah-langkah berikut:

1. Pergi ke halaman **[Releases](https://github.com/Kndy26/Temple-of-Banaspati-FPS/releases/tag/v1.0.0)** di sebelah kanan repositori ini.
2. Unduh file `.zip` versi terbaru.
3. **PENTING:** Jangan langsung membuka game dari dalam file ZIP. **Ekstrak (Unzip)** seluruh isi folder tersebut ke komputer Anda.
4. Buka folder hasil ekstrak dan jalankan file **`Temple Of Banaspati.exe`**.
